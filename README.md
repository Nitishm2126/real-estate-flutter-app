MCP Avadi — Real Estate CRM

MCP Avadi is a premium Real Estate Customer Relationship Management application built for the Madras City Properties (MCP) – Avadi Branch sales team.

The application helps sales teams manage customer leads, follow-ups, bookings, registrations, and sales activities through a centralized and responsive CRM platform.

The CRM supports complete follow-up lifecycle management:

Add follow-up notes
View today's follow-ups

Track overdue follow-ups
Mark follow-ups as completed

Manage multiple follow-ups for customers
